# LAXEE — Typography System

## 01 — Typography Philosophy

Typography is a core part of the LAXEE visual identity.

It should communicate:

- Elegance
- Restraint
- Modernity
- Clarity
- Sophistication

Typography should feel premium without becoming difficult to read.

---

# 02 — Typography Hierarchy

LAXEE uses a clear hierarchy:

1. Display
2. Heading
3. Subheading
4. Body
5. Caption
6. Label

Each level should have a distinct visual purpose.

# 08 — Recommended Direction

The visual direction should explore a combination of:

**Refined Serif + Modern Sans Serif**

The serif provides:

- Character
- Elegance
- Editorial quality

The sans serif provides:

- Clarity
- Modernity
- Functionality

The combination should remain restrained.

---

# 09 — Typography Rules

## Do

- Maintain consistent hierarchy.
- Use generous spacing.
- Prioritize readability.
- Use typography to create visual rhythm.
- Maintain consistent capitalization.
- Use approved fonts only.

## Do Not

- Use too many typefaces.
- Mix unrelated fonts.
- Use excessive font weights.
- Overuse uppercase text.
- Stretch or distort typefaces.
- Use decorative fonts for functional content.
- Reduce readability for aesthetic reasons.

---

# 10 — Letter Spacing

LAXEE typography should generally maintain comfortable spacing.

Small uppercase labels may use increased letter spacing to create
a refined editorial appearance.

Exact tracking values will be established after the final typefaces
are selected.

---

# 11 — Line Height

Recommended starting principles:

### Display

Approximately 100–120% of font size.

### Heading

Approximately 110–130%.

### Body

Approximately 140–170%.

These values are guidelines and should be adjusted according to the
selected typeface.

---

# 12 — Capitalization

### Brand Name

Preferred:

**L A X E É**

### Collection Names

Use title case where appropriate.

Example:

**Nikah Collection**

### Body Copy

Use normal sentence case.

Avoid unnecessary capitalization.

---

# 13 — Digital Typography

Website typography should prioritize:

- Readability
- Responsive scaling
- Clear hierarchy
- Fast loading
- Accessibility

The final web font implementation should be optimized for performance.

---

# 14 — Packaging Typography

Packaging typography should consider:

- Physical size
- Printing method
- Material
- Foil / embossing limitations
- Legibility
- Viewing distance

Typography should remain elegant when reproduced physically.
