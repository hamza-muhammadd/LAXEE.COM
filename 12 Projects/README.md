# LAXEE — Projects

**Status:** Active

## Purpose

Projects are temporary initiatives with a defined outcome, owner, scope, and completion condition.

## Examples

- First launch
- Nikah product development
- Packaging development
- Website rebuild
- Supplier onboarding
- Campaign launch

## Project Lifecycle

`Proposed → Approved → Active → Blocked / At Risk → Completed → Reviewed → Archived`

## Project Brief Standard

Every significant project should define:

- Objective
- Why it matters
- Owner
- Scope
- Non-goals
- Deliverables
- Dependencies
- Risks
- Milestones
- Success metrics
- Deadline
- Final outcome

## Rule

Projects do not become permanent departments. When a project creates a repeatable process, the resulting knowledge or SOP moves into the appropriate operating section.
