# Inaya Quran Academy — Parent Guidelines

**Status:** ACTIVE  
**Owner:** Founder / Operations  
**Version:** 1.0

## 1. Our role

Inaya provides structured Qur'an learning, teacher guidance, correction, practice expectations, and progress monitoring. Parents support the student's consistency and communication.

## 2. What parents should expect

Parents should receive a clear understanding of:

- The student's starting level.
- The student's current learning target.
- What the student should practice.
- What the teacher is correcting.
- How progress is reviewed.
- What the next target is.

## 3. What we expect from parents

- Help the student attend consistently.
- Support the agreed daily practice routine.
- Provide a suitable learning environment.
- Communicate schedule or availability changes early.
- Read progress updates and ask questions when something is unclear.
- Encourage the student without creating unhealthy pressure.

## 4. If a student struggles

The response should be:

**Identify → Diagnose → Adjust → Practice → Review.**

A struggle is not automatically a reason to move the student backward or increase workload. The teacher should identify the actual learning issue first.

## 5. Communication

Parent communication should be respectful, concise, factual, and focused on the student's learning.

Routine progress should be communicated through the agreed progress update process rather than through scattered messages.

## 6. Privacy

Student records, assessment details, parent contacts, and progress reports are private operational data. They must not be stored in the public GitHub repository.

## 7. Progress and completion

Completion is based on demonstrated learning outcomes, not simply the number of classes attended. When a student is ready, Inaya conducts the relevant assessment and recommends the next level or target.
