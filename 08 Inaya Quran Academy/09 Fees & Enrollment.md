## Enrollment flow

```text
Inquiry
  ↓
Free Assessment
  ↓
Level Recommendation
  ↓
Program + Schedule Recommendation
  ↓
Fee Confirmation
  ↓
Enrollment Confirmation
  ↓
Student Profile Created
  ↓
Classes Begin
```

## Enrollment checklist

- [ ] Student intake form completed.
- [ ] Live assessment completed.
- [ ] Level identified.
- [ ] Program confirmed.
- [ ] Schedule agreed.
- [ ] Fee communicated.
- [ ] Parent/student confirms enrollment.
- [ ] Payment method confirmed.
- [ ] Student ID created.
- [ ] Student profile added to private tracker.
- [ ] Teacher/class assigned.
- [ ] Personal learning plan created.
- [ ] First class scheduled.
